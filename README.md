# بوت تيليجرام لربط أرقام واتساب والتفاعل التلقائي مع الحالات

## ما يفعله البوت
- ربط أرقام واتساب عبر كود الاقتران من داخل تيليجرام.
- كل رقم يعمل في جلسة Baileys مستقلة بمجلد Auth خاص به.
- عند نجاح الربط، يتم فوراً وتلقائياً تفعيل:
  - 👁 مشاهدة (قراءة) كل الحالات الجديدة.
  - 😀 التفاعل (إيموجي) على كل الحالات الجديدة.
- إرسال رسالة ترحيب للرقم نفسه داخل واتساب بنفس نص رسالة تيليجرام.

## آخر التعديلات (2026-08)
- إصلاح تفاعل الحالات (كان يكتفي بالمشاهدة دون إرسال القلب). السبب كان تمرير رقم البوت نفسه داخل `statusJidList` مما يجعل واتساب يتجاهل التفاعل بصمت.
- ضبط `fromMe: false` داخل مفتاح التفاعل.
- إرسال رسالة ترحيب للرقم داخل واتساب لحظة نجاح الربط.
- ضمان تفعيل المشاهدة والتفاعل تلقائياً لكل رقم لحظة `connection === 'open'`.

## التشغيل
1. `cp .env.example .env` ثم ضع `TELEGRAM_TOKEN`.
2. `npm install`
3. `npm start`
