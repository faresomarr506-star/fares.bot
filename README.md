# بوت تليجرام لربط واتساب + تفاعل تلقائي على الحالات

بوت يعمل بـ **Node.js** بالكامل بدون أي موقع خارجي للربط.
يقوم بربط أرقام واتساب عبر **كود اقتران (Pairing Code)** من 8 أرقام،
ويحفظ الجلسات في **MongoDB** فيبقى الأرقام مربوطة حتى بعد إعادة تشغيل
السيرفر، ويفعّل خاصية **التفاعل التلقائي على الحالات (Status)** لكل رقم
بإيموجي يختاره المستخدم.

---

## ✨ المميزات

- 🔐 ربط الرقم عبر كود اقتران من 8 أرقام (يتم إرساله من بوت تليجرام مباشرة، لا QR ولا مواقع خارجية).
- 🗄 حفظ الجلسة في MongoDB (مجموعة `baileys_creds` و`baileys_app_state`) — لا ملفات محلية.
- 🔄 إعادة تشغيل البوت ترجع الجلسات تشتغل تلقائياً بدون الحاجة لإعادة الربط.
- ⚡ التفاعل على الحالات بأقل من ثانية (event-driven، بدون polling).
- 😍 كل رقم تربطه له إيموجي إعداداته الخاصة (يمكنك وضع أكثر من إيموجي، يختار البوت واحداً عشوائياً لكل حالة).
- 🧑‍🤝‍🧑 دعم أكثر من رقم وأكثر من مستخدم تليجرام مع عزل تام بينهم.
- ⏱ ميزة الشهر الكامل للتفاعل قائمة ما دام السيرفر شغالاً و MongoDB متاحة.

## 🚀 التشغيل

### 1) تجهيز البيئة

انسخ `.env.example` إلى `.env` وضع القيم:

```env
BOT_TOKEN=123456:ABCDEF...        # من @BotFather
MONGO_URI=mongodb+srv://faresomar79:faresaltmimi99@cluster0.0tb0uf9.mongodb.net/?appName=Cluster0
DB_NAME=wa_telegram_bot
```

### 2) تثبيت الحزم

```bash
npm install
```

### 3) تشغيل البوت

```bash
# تشغيل مباشر
npm start

# أو عبر pm2 للتشغيل 24/7 (الأفضل للسيرفرات)
npm i -g pm2
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

### 4) عبر Docker

```bash
docker compose up -d --build
```

## 🤖 أوامر البوت

بعد إرسال `/start` تظهر قائمة بأزرار شفافة:

| الزر            | الوظيفة                                             |
|-----------------|----------------------------------------------------|
| 📲 ربط رقم جديد | يطلب الرقم (مفتاح الدولة + الرقم، أرقام فقط بدون +) |
| 📋 أرقامي المربوطة | يعرض كل الأرقام المربوطة وإيموجيها وحالة الاتصال |
| 😀 تغيير إيموجي التفاعل | يعرض الأرقام، بعد اختيار الرقم يستقبل الإيموجي الجديد(ة) |
| 🗑 حذف رقم | يفصل الرقم نهائياً من البوت ويشيله من القاعدة |
| 📊 حالة البوت | يعرض حالة البوت وعدد الأرقام المربوطة والمتصلة فعلياً |

### سيناريو الربط

1. أرسل `/start`.
2. اضغط **📲 ربط رقم جديد**.
3. أرسل الرقم بهذا الشكل: `9665XXXXXXXX`  (مفتاح الدولة، بدون +، بدون مسافات).
4. يستقبل البوت كود اقتران من 8 أحرف.
5. افتح واتساب ➜ الإعدادات ➜ الأجهزة المرتبطة ➜ ربط جهاز ➜ **ربط برقم**.
6. أدخل الكود.

### سيناريو تغيير الإيموجي

1. اضغط **😀 تغيير إيموجي التفاعل**.
2. اختر الرقم من القائمة.
3. أرسل الإيموجي الجديد. مثال: `❤️ 🔥 🥹 👍`.

كل رقم يحفظ إيموجيه بشكل منفصل، والبوت يختار عشوائياً بينها عند كل تفاعل.

## 🗄 القاعدة (MongoDB)

- `users` — بيانات مستخدم تليجرام وقائمة أرقامه مع الإيموجي وحالة كل رقم.
- `baileys_creds` — `creds` لكل رقم.
- `baileys_app_state` — مفاتيح الإشارة لكل رقم.

كل شيء معزول بـ `telegramId` ← لا يستطيع مستخدم رؤية أو تعديل أرقام مستخدم آخر.

## 📝 ملاحظات هامة

- البوت لا يطلب تثبيت WhatsApp Business ولا استخدام API رسمي،
  بل يستخدم مكتبة `@whiskeysockets/baileys` (multi-device).

- لضمان بقاء التفاعل على الحالات **شهراً كاملاً** يجب تشغيل البوت على
  VPS شغال 24/7 (مثل Hetzner, Contabo, DigitalOcean) أو على Railway/Render،
  أما تشغيله على جهازك الشخصي فينقطع عند إغلاق اللابتوب.

- لم يتم اختبار الكود برقم واتساب حقيقي من قبل مزود البوت، تحتاج لاختباره بنفسك.

## 🆘 حل المشاكل الشائعة

| المشكلة                                  | الحل                                                                  |
|------------------------------------------|-----------------------------------------------------------------------|
| `pairing failed`                         | أعد تشغيل البوت وحاول مرة أخرى بعد دقيقة.                           |
| `getaddrinfo EAI_AGAIN cluster0...`      | تأكد من اتصال الإنترنت وأن الـ IP مفعّل في Network Access بـ Atlas. |
| رمز غير مقبول من واتساب                  | قد يحظر واتساب ربط نفس الرقم مرات كثيرة في وقت قصير، انتظر قليلاً.  |
| البوت توقف التفاعل                       | تأكد أن `pm2 status` يعمل وراجع `pm2 logs`.                          |
